# Добавление элемента через данные

Пример: добавить событие «Чаевые постоянного клиента» в вечернюю смену (`Work2`) так, чтобы оно
появилось сразу после первого посетителя. Код (`.gd`) и сцена (`.tscn`) не меняются.

## Инструкция

1. Откройте `content/content.json` в любом текстовом редакторе.
2. В массив `events` добавьте объект с **новым уникальным** `id`, текстом и эффектом:

   ```json
   {
   	"id": "regular_tips",
   	"text": "Постоянный клиент оставил щедрые чаевые.\nКто-то помнит, как вы помогли ему раньше.",
   	"animation": "default",
   	"money": 20,
   	"respect": 5
   }
   ```

3. В массив `insertions` добавьте место появления: имя смены, индекс в её последовательности и
   `id` события:

   ```json
   { "work": "Work2", "position": 2, "event": "regular_tips" }
   ```

   В `Work2` последовательность такая: `[вступление, Car, Car2, donation]`. Индекс `2` ставит
   событие перед `Car2`, то есть после первого посетителя. Индекс `-1` — в самый конец.
4. Сохраните файл (между элементами массивов нужны запятые, у последнего элемента запятой нет).
5. Запустите игру (F5). В консоли Godot должна появиться строка:
   `Контент: загружен=true, событий=2, вставок=2, проблем=0`.
   Если `проблем` больше нуля, ниже в журнале перечислено, какая запись и почему пропущена.

`content/content.json`.

## Как показать новый элемент в игре

1. Запустите игру с исходным `content.json` и дойдите до вечерней смены: после первого посетителя
   сразу идёт второй.
2. Подставьте `content.after.json` и запустите снова. В вечерней смене после ответа первому
   посетителю появляется панель с текстом «Постоянный клиент оставил щедрые чаевые…», а шкалы
   денег и репутации растут на 20 и 5. Сделайте скриншот панели и консоли с строкой о загрузке.
3. Без запуска игры то же самое проверяют автотесты (`_test_extension_through_data`):
   файл `before` даёт в `Work2` 4 элемента, файл `after` — 5, и на индексе 2 стоит `regular_tips`.

## Правила и границы

- Событие с отрицательными деньгами не применится, если баланса не хватает: оно пропускается,
  деньги и репутация не меняются.
- Повторяющийся `id`, неизвестный `event` в `insertions`, дробные числа и значения вне диапазона
  отклоняют только свою запись; остальные загружаются. Полный список реакций — в
  [architecture.md](architecture.md#8-ошибочные-и-граничные-данные).
- Пример файла с намеренными ошибками — [examples/content.invalid.json](examples/content.invalid.json).
